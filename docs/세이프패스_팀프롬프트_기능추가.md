## 3. 정한 것 (팀원 프롬프트와 다르게 한 부분)

- **도보 시간**: 팀 프롬프트의 `×1.3 ÷ 70m` 대신 기존 `×1.5 ÷ 80m` 유지 (카카오맵 도보 결과에 맞춘 값). 경로를 그리면 틈길 엔진의 실제 시간. 상수는 `WALK = {detour, mpm}` 한 곳.
- **샘플 데이터**: AED · 대피소는 **가짜 위치를 만들지 않았다.** 긴급 상황에서 틀린 위치는 위험하기 때문. 공공데이터가 연결되기 전에는 「연결되면 표시 · 안전디딤돌 앱에서 확인」 안내만 보인다.
  - 응급실 · 약국은 키 승인 전에도 **카카오 장소검색 실시간 결과**를 쓴다 (실제 장소, 출처 「Kakao Map」 표시). 약국 영업 여부는 국립중앙의료원 API가 연결되어야 나온다 (그전에는 「영업시간 미확인 — 먼저 전화」).
- **네이버 지도**: 앱이 있으면 공식 URL 스킴 `nmap://route/walk`, 없으면 네이버 지도 웹 **검색**으로 연다. 웹 길찾기 주소 형식은 공식 문서에서 확인되지 않아 쓰지 않았다.
- **안전디딤돌 링크**: 앱이 2026년에 새 버전으로 바뀌는 중이라 패키지 주소 대신 구글플레이 검색 · 앱스토어 행정안전부 개발자 페이지로 연결.
- **공공누리**: 서울시 누리집 문장은 영어 원문 그대로만, 다른 언어는 사실만 우리 말로 (앞선 원칙 유지).

## 4. sp_data.json 추가 필드

```json
"phrases": [
  {"id": "taxi", "need": ["addr"], "ko": "이 주소로 가 주세요: {addr}", "en": "Please take me to this address: {addr}", "zh": "…", "ja": "…"},
  {"id": "way",  "need": ["place"], "ko": "{place}에 가려면 어떻게 가야 하나요?", "…": "…"},
  {"id": "toilet"}, {"id": "order", "need": ["menu"]}, {"id": "mild"}, {"id": "nomeat"},
  {"id": "allergy", "need": ["ing"]}, {"id": "pharm", "need": ["sym"]}, {"id": "help"}
],
"phraseFill": {
  "sym": [{"ko": "두통", "en": "a headache", "zh": "头痛", "ja": "頭痛"}, "복통", "감기", "상처"],
  "ing": ["땅콩", "갑각류(새우·게)", "우유", "달걀", "밀", "돼지고기"]
}
```

- `id`: 문장 이름 · `need`: 채워야 할 칸 (없으면 그 문장은 목록에서 빠짐) · `{addr}` `{place}` `{menu}` `{sym}` `{ing}`: 자동으로 채움.
- 한국어 문장은 장소 · 메뉴를 한글 그대로, 번역 줄은 그 언어 이름으로 채운다.

## 5. 환경 변수 · 활용신청할 API

키는 지금처럼 `DATA_GO_KR_KEY` 하나로 쓴다. 공공데이터포털에서 **아래 서비스를 각각 「활용신청」** 해야 응답이 온다. 서비스 주소가 바뀌면 `.env` 에 괄호 안 이름으로 넣으면 된다 (안 넣으면 아래 기본값).

| 화면 | API (공공데이터포털) | 기본 주소 | 주의 |
|---|---|---|---|
| 약국 (영업 여부) | 국립중앙의료원_전국 약국 정보 조회 서비스 (15000576) | `.../B552657/ErmctInsttInfoInqireService/getParmacyListInfoInqire` (`nmcPharmacyApi`) | `Q0=서울특별시&Q1=성북구`, 요일별 `dutyTime1s~8c` |
| 응급실 | 국립중앙의료원_전국 응급의료기관 정보 조회 서비스 | `.../B552657/ErmctInfoInqireService/getEgytListInfoInqire` (`nmcEmergencyApi`) | 승인 전에는 카카오 「응급실」 검색으로 대신 |
| AED | 국립중앙의료원_전국 자동심장충격기(AED) 정보 조회 서비스 (15000652) | `.../B552657/AEDInfoInqireService/getEgytAedManageInfoInqire` (`nmcAedApi`) | 응답 필드(`org`, `buildPlace`, `wgs84Lat/Lon`)는 승인 뒤 실제 응답으로 한 번 확인 |
| 대피소 | 행정안전부_민방위대피시설 조회서비스 (15155067) | `https://apis.data.go.kr/1741000/civil_defense_shelter_info` (`civilShelterApi`) | 좌표가 EPSG:5174 라 승인 뒤 변환 코드를 맞춰야 함. 행정안전부_지진옥외대피장소(15138868)는 명세 확인 후 추가 |

- 서버 `/api/safety?set=pharm|er|aed|shelter` · 5초 안에 응답이 없으면 화면은 카카오 · 안내로 대신하고, 전화번호 · 주소 카드는 항상 보인다.
- Vercel 에는 이미 `DATA_GO_KR_KEY` 가 들어가 있으니 **새로 넣을 키는 없다.** 승인만 되면 바로 실데이터.
