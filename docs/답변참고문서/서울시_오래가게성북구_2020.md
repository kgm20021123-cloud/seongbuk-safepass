# 서울 오래가게 (성북구)

- 출처: 서울시 「내 손안에 서울」 「'오래가게'로 감성여행 떠나요...동북권 21곳 선정」 (2020-11-10, https://mediahub.seoul.go.kr/archives/1301748)
- 2020년 선정 자료다. 지금도 영업하는지는 확인 필요
- 기사에 주소가 없다. 주소를 물으면 「자료 없음」으로 답하고 120 다산콜센터를 안내한다
- 문의: 120 다산콜센터
