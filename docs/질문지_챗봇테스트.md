# 챗봇 테스트 질문지 (성북 세이프패스)

- 기획서 4-2 메뉴를 기준으로 외국인 관광객이 물을 만한 질문 10개
- 「기대 답」은 근거 문서에 있는 내용만 쓴다. 근거가 없으면 「자료 없음 + 문의처」가 맞는 답이다
- 이 파일은 답변 근거가 아니라 시험용이다 (답변참고문서에 넣지 않는다)

| # | 질문 (영어) | 근거 문서 | 기대 답 | 상태 |
|---|---|---|---|---|
| 1 | Is the air bad today? Do I need a mask? | 에어코리아 실시간 API (측정소 「성북구」) | 오늘 PM10 · PM2.5 수치와 등급. 「나쁨」 이상이면 마스크 안내 고정 문장 | API 연결 필요 |
| 2 | Will it rain today? From what time? | 기상청 단기예보 API (nx 60, ny 127) | 강수확률 60% 이상인 시간대와 우산 안내 고정 문장 | 프로토타입 v2 연결됨 |
| 3 | What can I visit within walking distance of my stay? | 성북구청_관광지운영안내_2026, 서울시_한양도성관심지점(영문) | 숙소에서 가까운 순 관광지 이름 · 주소 | 문서 있음 |
| 4 | Any indoor places to visit on a rainy day? | 성북구청_관광지운영안내_2026 | 이태준 가옥(수연산방), 최순우 옛집(12~3월 휴관), 성북구립미술관, 성북선잠박물관 | 문서 있음 |
| 5 | Is Gilsangsa open now? Is there an entrance fee? | 성북구청_관광지운영안내_2026 | 4~9월 03:30–19:00, 10~3월 03:30–20:00, 입장료 무료 | 문서 있음 |
| 6 | Any long-running local restaurants near my stay? | 서울시_오래가게성북구_2020, 백년가게 API | 나폴레옹과자점 · 봉화묵집 · 보헤미안커피하우스 + 「영업 여부 확인 필요」 | 백년가게 받기 필요 |
| 7 | What events are on in Seongbuk this week? Are they free? | 서울시_문화행사정보 (성북구만), 성북구청_축제안내_2026 | 이번 주 행사 이름 · 기간 · 장소 · 유무료 (원래 데이터 그대로) | 문서 정리 필요 |
| 8 | When and where do I put out the trash? Where can I buy bags? | 행정안전부_생활쓰레기배출정보, 성북구청_생활안내_2026, 봉투 판매소 API | 숙소 동의 배출 요일 · 18:00–20:00 · 건물 앞, 편의점에서 종량제 봉투 | 판매소 받기 필요 |
| 9 | Where is the nearest police box or community center? | 경찰청_지구대파출소주소, 성북구청_생활안내_2026, 동주민센터 API | 가까운 지구대 · 파출소 이름 · 주소, 주민센터, 긴급 112 | 주민센터 받기 필요 |
| 10 | How do I take the subway? Where do I get a transit card? | 서울시_교통카드이용안내_2026 | 기후동행카드 관광권 가격 · 사는 곳, 해외 카드로 역 발매기에서 구매 | 문서 있음 |

## 답하면 안 되는 질문 (자료 없음 확인용)
- 「최순우 옛집 관람료가 얼마예요?」 → 자료 없음, 1330 안내
- 「봉화묵집 주소 알려 주세요」 → 자료 없음, 120 안내
