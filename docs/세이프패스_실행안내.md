# 세이프패스 실행 안내 (team3_project)

## 실행

1. `team3_project` 폴더의 **`세이프패스_실행.bat`** 더블클릭
2. 브라우저가 `http://localhost:5173` 으로 열린다 (카카오 콘솔에 등록된 주소)
3. 휴대전화는 같은 와이파이에서 검은 창에 나온 주소로 (시연판의 QR을 찍어도 됨)

세이프패스 v1~v3 나 틈길이 켜져 있으면 먼저 닫는다 (같은 5173 포트).

## 폴더 구조 (Vercel 배포와 같은 모양)

| 위치 | 내용 |
|---|---|
| `public/index.html` | 화면 (세이프패스 v3 디자인) |
| `public/sp_data.json` | 저장해 둔 공공데이터 (쓰레기 요일 · 화장실 · 와이파이 · 지구대/파출소 · 한식 800선 · 한양도성 · 통계) |
| `public/qrcode.js`, `sp-icon-*.png`, `sp-manifest.json` | QR 만들기, 앱 아이콘 |
| `api/_safepass.py` | 서버 기능 모음. 키는 `.env` 에서만 읽는다 |
| `api/config.py` 등 7개 | Vercel 서버 함수 (`/api/config`, `/api/weather`, `/api/data`, `/api/events`, `/api/tour`, `/api/walk`, `/api/dust`) |
| `api/_walk_engine3.py`, `api/_data/walk_graph_v10_2.json.gz` | 틈길 도보 경로 엔진 · 성북 · 종로 보행 네트워크 |
| `tools/로컬서버.py` | 내 PC에서 `public` + `api` 를 띄우는 서버 |
| `vercel.json` | 배포 때 `api` 폴더 파일을 서버 함수에 함께 넣는 설정 |

## 화면에서 실시간으로 받는 것 (새 API)

| 화면 | 데이터 | 서버 기능 | .env 이름 |
|---|---|---|---|
| 오늘 날씨 | 기상청 단기예보 | `/api/weather` | `DATA_GO_KR_KEY`, `kmaShortForecastApi` |
| 미세먼지 | 에어코리아 측정소별 실시간 측정 (성북구 측정소, 최근 18시간) | `/api/dust` | `DATA_GO_KR_KEY` (활용신청 승인 필요), 주소를 바꿀 때만 `airKoreaApi` |
| 관광지 탭 「가까운 공식 관광정보」 | 한국관광공사 영 · 일 · 중 · 국문 관광정보 (숙소 반경 2km, 화면 언어대로) | `/api/tour` | `DATA_GO_KR_KEY`, `ktoEngTourApi` 등 |
| 먹거리 탭 「백년가게」 | 소상공인시장진흥공단 백년가게 (성북구) | `/api/data?set=baengnyeon` | `DATA_GO_KR_KEY`, `baengnyeonShopApi` |
| 축제 탭 | 서울시 문화행사 (성북구 · 진행 중 · 예정) | `/api/events` | `seoulOpenDataKey`, `seoulCultureEventApi` |
| 생활 탭 「가장 가까운 주민센터」 | 성북구 동주민센터 (좌표) | `/api/data?set=center` | `DATA_GO_KR_KEY`, `sbCommunityCenterApi` |
| 생활 탭 「우리 동 종량제 봉투 파는 곳」 | 성북구 규격봉투 판매소 | `/api/data?set=bagshop` | `DATA_GO_KR_KEY`, `sbTrashBagShopApi` |
| 행사 이름 · 백년가게 이름의 짧은 번역 (영 · 중 · 일) | AI 번역 (Groq, 안 되면 Gemini). 이름은 원래 한글 그대로 두고 아래 줄에 「AI translation」 표시 | `/api/translate` | `GROQ_API_KEYS`, `GEMINI_API_KEYS` (모델을 바꿀 때만 `GROQ_MODEL`, `GEMINI_MODEL`) |
| 지도 도보 경로 | 틈길 엔진 (없으면 OpenStreetMap) | `/api/walk` | 필요 없음 |
| 지도 | 카카오 지도 | `/api/config` 가 키를 알려 줌 | `javascriptKey` |

- 받아 온 결과는 서버가 저장해 두고 다시 쓴다 (날씨 · 미세먼지 30분, 문화행사 6시간, 그 밖 12시간).
- 실패하면 `sp_data.json` 저장본이나 예전 값으로 그대로 보인다.
- 출연자 실명 · 문의 연락처 · 숙소 전화번호처럼 개인정보가 섞일 수 있는 칸은 서버가 보내지 않는다.

## Vercel 배포 (2026-11-11 준비 완료)

순서는 `docs/배포가이드.md` 그대로 하고, 세이프패스는 아래만 더 한다.

| 언제 | 할 일 |
|---|---|
| 올리기 전 | `tools\배포_점검.py` 실행 → 「문제 없음」인지 본다. `.env` 가 막혀 있는지, 키 값이 다른 파일에 들어갔는지, Vercel 에 넣을 이름이 다 있는지 확인한다 (키 값은 화면에 안 나옴) |
| Vercel ⑤ | **Import .env** 로 `.env` 전체를 넣는다. 키뿐 아니라 서비스 주소(`baengnyeonShopApi`, `sbCommunityCenterApi`, `sbTrashBagShopApi` 등)도 서버가 읽는다 |
| 배포 뒤 | 카카오 개발자 콘솔 → 내 애플리케이션 → 플랫폼 → **Web 사이트 도메인**에 배포 주소(`https://○○.vercel.app`)를 추가한다. 안 하면 지도만 안 나온다 |
| 배포 뒤 확인 | `https://○○.vercel.app/api/config` → `hasDataKey`, `hasSeoulKey` 가 `true` 인지 · `/api/weather`, `/api/events` 가 `"ok": true` 인지 |

이번에 바꾼 것

- `vercel.json`: 서버 함수를 **서울(icn1)** 에서 돌린다 (공공데이터 API · 이용자 모두 한국이라 빠름), 최대 60초 (문화행사 약 2만 건 받기)
- `api/_vercel.py`: 8개 서버 함수의 공통 틀. 성공한 응답은 Vercel CDN 이 잠시 저장해 다시 쓴다 (날씨 · 미세먼지 30분, 문화행사 6시간, 관광 · 생활 12시간, 번역 · 도보 경로 7일) → 공공데이터 호출 횟수와 첫 화면 시간이 줄어든다. 실패한 응답은 저장하지 않는다
- `.gitignore`: `frontend-design_최신판/` 도 올리지 않음
- 내 PC 서버(`세이프패스_실행.bat`)는 그대로 쓴다. 휴대전화 QR 주소는 배포본에서는 그 배포 주소로 자동으로 바뀐다
- 확인: Vercel 처럼 함수 파일을 하나씩 따로 불러 8개 모두 응답 확인 (키 없이: 도보 경로 정상, 나머지는 「키 없음」 안내)
